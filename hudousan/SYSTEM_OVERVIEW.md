# 駐車監視員検出システム - システム概要

## システムの目的

このシステムは、**指定された特徴を持つ駐車監視員のみを検出**するためのカスタム機械学習モデルを構築・運用します。

### 検出対象の特徴

以下の**すべて**の特徴を満たす人物のみを検出します:

1. ✅ 緑色または黄緑色の制服を着用している
2. ✅ 蛍光色の反射安全ベストを着用している
3. ✅ 制帽または作業用キャップを着用している
4. ✅ 肩掛けの業務用バッグを所持している
5. ✅ 手にハンディ端末、スマートフォン、または撮影機器を持っている
6. ✅ 路上に駐車されている車両のフロント付近またはナンバープレート周辺を確認する動作をしている

**重要**: これらの特徴をすべて満たさない人物は検出されません。

## システム構成

### 1. 画像収集モジュール (`collect_images.py`)
- ネットから駐車監視員の画像を自動収集
- 複数の検索クエリを使用
- 手動での画像追加も可能

### 2. アノテーションツール (`annotate_images.py`)
- 収集した画像にバウンディングボックスを描画
- YOLO形式のラベルファイルを生成
- インタラクティブなGUI

### 3. モデルトレーニング (`train_model.py`)
- YOLOモデルのファインチューニング
- データセットの自動分割（訓練/検証）
- ハイパーパラメータの調整

### 4. 継続的トレーニング (`continuous_training.py`)
- 画像収集 → トレーニング → 評価の自動ループ
- 目標精度に達するまで継続的に改善
- トレーニング履歴の管理

### 5. 検出システム (`clone_home.py`)
- リアルタイム検出
- 監視エリアへの滞在時間計測
- アラーム機能

## 使用方法

### 自動モード（推奨）

```bash
./start_training.sh
```

### 手動モード

1. **画像収集**
   ```bash
   python3 collect_images.py --max-images 100
   ```

2. **アノテーション**
   ```bash
   python3 annotate_images.py
   ```

3. **トレーニング**
   ```bash
   python3 train_model.py --split-dataset --epochs 100
   ```

4. **検出実行**
   ```bash
   python3 clone_home.py --model runs/detect/parking_officer/weights/best.pt
   ```

## 重要なポイント

### 1. アノテーションの重要性
- **正確なアノテーションが精度に直接影響します**
- 指定された特徴をすべて満たす人物のみをラベル付けしてください
- 特徴が不足している人物はラベル付けしないでください

### 2. データ量
- 最低50枚以上、推奨100枚以上の画像が必要
- 多様な角度、照明条件、背景の画像を収集

### 3. 継続的改善
- 一度のトレーニングで完璧なモデルは作れません
- `continuous_training.py`を使用して継続的に改善
- 誤検出があった場合は、その画像を追加して再トレーニング

### 4. 検出の精度
- トレーニング済みモデルを使用することで、汎用のperson検出よりも精度が向上
- 指定された特徴を持つ人物のみを検出
- それ以外の人物は検出されません

## トラブルシューティング

### 画像が収集できない
- ChromeDriverがインストールされているか確認
- 手動で画像を `dataset/images/` に配置することも可能

### トレーニングエラー
- データセットディレクトリの構造を確認
- 画像とラベルのファイル名が一致しているか確認

### 検出精度が低い
- より多くの画像を収集
- アノテーションの精度を確認
- トレーニングエポック数を増やす

## 次のステップ

1. `./start_training.sh` を実行して継続的トレーニングを開始
2. 十分な精度に達するまで待機（数時間〜数日かかる場合があります）
3. ベストモデルを使用して検出を実行

詳細は `README_TRAINING.md` を参照してください。
